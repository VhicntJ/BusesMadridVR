# Buses Madrid - Sitio Web

Sitio web moderno para Buses Madrid, empresa de transporte con más de 35 años de experiencia en Chile.

## 🚌 Características

- **Next.js 15** con App Router
- **TypeScript** para type-safety
- **Tailwind CSS** para estilos
- **Framer Motion** para animaciones fluidas
- **Optimización SEO** completa (JSON-LD, sitemap, robots.txt)
- **Componentes reutilizables** y optimizados
- **Imágenes responsivas** con next/image

## 📋 Servicios

- Transporte corporativo
- Transporte minero
- Transporte de turismo
- Arriendo de flotas
- Servicio ejecutivo y de personal

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Producción
npm run build
npm run start
```

## 📊 Estructura

```
src/
├── app/              # Rutas y layout global
├── components/       # Componentes reutilizables
├── lib/             # Utilidades y datos
└── styles/          # Estilos globales
```

## 🔍 SEO

- Metadata dinámica para cada página
- JSON-LD estructurado (Organization + LocalBusiness)

- Open Graph configurado
